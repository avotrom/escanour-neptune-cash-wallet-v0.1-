              Servers

              Use your own neptune-core for everything: syncing, sending and fast restore. No outside server learns your IP, when you are online, or which coins are yours.

              neptune-core --listen-rpc --rpc-modules Node,Chain,Wallet,Utxoindex --utxo-index

              Add --network testnet for Testnet. --utxo-index (and the Utxoindex module) is only needed for fast restore. Keep the RPC port on 127.0.0.1; never expose it to the internet.

                Tor

                What goes through Tor

                  Only these. Your node on this computer is reached directly, and the rest of Chrome is not touched. If Tor stops, the wallet stops connecting instead of using your IP.

                  Set up Tor on your Mac

                  1. Easiest: Tor BrowserDownload it from torproject.org, open it and keep it open. Port 9150.
                  2. Or the tor service (Homebrew)Runs in the background, no window. Port 9050.
                    brew install tor && brew services start tor
                  3. Then turn on Connect through TorChrome asks once to let the wallet set a proxy for its servers. The light turns green when requests arrive through Tor.

                  Through Tor, syncing is slower. A VPN or another proxy extension can block it. Using one server for both syncing and sending still lets it link them by timing.

                      Authenticator

                      Authenticator app

                      This local approval guard requires a fresh six-digit code for unlock, sending, key reveal, backup operations and destructive actions. It cannot protect a stolen recovery phrase or a compromised browser profile.

                      Add this secret to your authenticator app as a time-based account (SHA-1, six digits, 30 seconds).

        How this is measured
        
                            When you spend a coin, the network sees 45 positions in the mutator set's Bloom filter. Those positions narrow the coin's origin down to a range of receipts, but not to one: any receipt in the range could be yours. The number above is the size of that range for your least hidden coin, computed with Neptune's own rule (AbsoluteIndexSet::aocl_range). Amounts and addresses are never visible on-chain.
